Combine Foster/Adopter

About This Tool

Upload one or more Excel exports (adopter lists, willing foster lists, or both) and this tool will combine them into a single spreadsheet, merging records for the same person together.

How It Works

  • Upload any number of Excel files (.xls or .xlsx) — mix adopters and fosters freely
  • Each sheet is automatically classified as an Adopter list or a Foster list by looking at its column names
  • The tool automatically finds each sheet's email column and name column, whatever they happen to be called (e.g. "Outcome To Email" vs "Primary Email")
  • You'll be shown the detected files/sheets and asked which columns to keep in the final spreadsheet
  • Records are merged using the same rules as the Email-Name Dedup tool:
    • Primary key: Email address (case-insensitive)
    • Fallback key: First + Last name, split automatically from the detected name column
    • When the same person appears more than once, non-empty values fill in any blanks
  • Download the combined data as a single XLSX file

🔒 Privacy First: Your data is never stored long-term. Files are processed in memory and automatically deleted shortly after conversion.
