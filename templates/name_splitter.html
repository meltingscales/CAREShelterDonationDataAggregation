Name Splitter

About This Tool

The Name Splitter utility helps you split full names in your spreadsheet into separate "First Name" and "Last Name" columns using multiple algorithms. This is useful when you have a single "Name" field but need to separate it into components.

How It Works

  • Upload any Excel file (.xls or .xlsx)
  • Specify which column contains the names you want to split
  • The tool will process all sheets in your workbook
  • Each algorithm will add two new columns to your data
  • Download the result as a CSV file with all the original data plus the new name columns

Example

If you have a column called "Name" with values like "John Doe", "Doe, Jane", or "Bob (Smith)", the tool will create multiple columns showing how each algorithm splits the name. You can then choose which algorithm works best for your data.

🔒 Privacy First: Your data is never stored. Files are processed in memory and immediately deleted after conversion.
