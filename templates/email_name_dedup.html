Email then Name Deduplication

About This Tool

This tool performs deduplication on your Excel spreadsheet data using email addresses as the primary key and first+last name combination as a fallback. Unlike the main aggregation tool, this preserves all your original columns and sheet structure.

How It Works

  • Upload any Excel file (.xls or .xlsx)
  • The tool will process all sheets in your workbook
  • Deduplication logic:
    • Primary key: Email address (case-insensitive)
    • Fallback key: First Name + Last Name (case-insensitive)
    • Records with no email AND no name are skipped
  • All your original columns are preserved
  • Download the deduplicated data as an XLSX file
  • View a detailed deduplication log showing what was merged

Deduplication Rules

  1. Email-based matching: Records with the same email address (case-insensitive) are considered duplicates
  2. Name-based fallback: If no email is present, records with the same First Name + Last Name combination are considered duplicates
  3. First occurrence wins: When duplicates are found, the first occurrence is kept and subsequent ones are removed
  4. Sheet-by-sheet: Deduplication is performed within each sheet independently

Example

If your spreadsheet has these records:

Email First Name Last Name Phone Address
john@example.com John Doe 555-1234 123 Main St
JOHN@EXAMPLE.COM Johnny Doe 555-5678 456 Oak Ave
Jane Smith 555-9999 789 Elm St
Jane Smith 555-8888 321 Pine Rd

Result: 2 unique records (John Doe and Jane Smith). The highlighted rows are duplicates that will be removed.

🔒 Privacy First: Your data is never stored. Files are processed in memory and immediately deleted after conversion.
