Name Fixer

About This Tool

The Name Fixer cleans up inconsistent capitalization in your spreadsheet, such as names typed in ALL CAPS (JANE SMITH) or all lowercase (jane smith), so they read Jane Smith.

How It Works

  • Upload a CSV (.csv) or Excel file (.xls or .xlsx)
  • Enter the column(s) to fix, separated by commas (e.g. First Name, Last Name). Upper/lower case and extra spaces in the column names don't matter.
  • Pick a normalization style
  • Only the columns you list are changed; every other column is left exactly as it was
  • Download the result as a CSV file. If your workbook has several sheets, all of them are included and a Source Sheet column shows where each row came from.

"Only fix values that are all caps or all lowercase"

With this option on (the default), a value is only changed if every letter in it is uppercase or every letter is lowercase. Names that already mix upper and lower case, like DeAndre, MacKenzie or van der Berg, were probably typed correctly and are left alone. Turn it off to re-capitalize every value.

Limitations

Some names can't be fixed reliably from all-caps text: MACDONALD becomes Macdonald, DE LA CRUZ becomes De La Cruz, and DEANDRE becomes Deandre. Give the results a quick look before importing.

🔒 Privacy First: Your data is never stored. Files are processed in memory and immediately deleted after conversion.

Fix Capitalization in Your Spreadsheet



💡 How to fill in this box

Type the column name exactly as it appears in the top row of your spreadsheet.

To fix more than one column, put a comma ( , ) between each name.

One column: Name
Two columns: First Name, Last Name
Three columns: First Name, Last Name, City

Capital letters and extra spaces in the column names don't matter: first name works the same as First Name.






Tip: Only list name or address columns. Running this on columns like email addresses, IDs or state abbreviations will change their capitalization too.
